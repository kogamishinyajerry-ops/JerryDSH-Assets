## 实测失败与修复记录

- npm 子进程未保留必要 CA 路径导致 TLS 校验失败：保留 CA 配置后复测，未关闭 TLS 校验。
- runtime 锁沿用 legacy peers 漏掉必需 Cordis peer：固定宿主使用完整 peer 锁，三个 profile 保留各自原安装策略。
- FastMCP banner 版本查询因代理依赖而崩溃：使用官方配置关闭该非必要查询，真实 MCP 握手随后通过。
- OpenFOAM v1912 functionObjects 出现 SHA1 stream 错误：固定配方用官方独立导出器，原失败保留。
- PID namespace 与 host /proc 不同：补两侧身份匹配与退出证明。
- SQLite 字符串 URL 在带 ? 的目录可能指向旧库：改为 URL 对象，并通过 sentinel 旧库零改写回归。
- Git shell 没有 GitHub 写凭据：使用用户已连接的 GitHub 应用提交审查分支，不读取或索取个人 token。
- web 保留一条 vision-toolkit 禁用目标不存在的旧快照告警；该告警不影响双禁，未擅自删除用户原禁用意图。
