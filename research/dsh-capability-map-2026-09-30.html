02COMAC 辅助动力部业务全景（四大域 18 象限）

这是覆盖判定的分母：核心工程 6 + 日常事务 4 + 协作治理 4 + 支撑环境 4。

核心工程域 APU 设计师主战场

  • 设计建模（CATIA / CMOS / PDM）
  • 仿真分析（STAR-CCM+ / 性能计算）
  • 安全性与适航（FMEA / FTA / 条款）
  • 故障情报与知识（P-ACE / TeamBrain）
  • 试验与验证（大纲 / 数据 / 报告）
  • 智能平台建设（FDE 团队 / 工具链）

日常事务域 高工时粘合剂

  • 文档报告（技术报告 / PPT / 纪要成文）
  • 会议协作（纪要智能体 / 多科室协调）
  • 数据表格（台账 / TeamBrain 维护）

协作治理域 团队合规基础

  • 团队协作（群聊协作 / 共享记忆）
  • 权限与密级（分区 / 审计）

  • 知识沉淀（决策追溯 / 培养）

支撑环境域 底座约束

  • 内网物理隔离（U 盘摆渡 / 离线部署）
  • 国产化信创（Win10 / 麒麟适配）

05内网缺口重估（09-30 进展确认后）

原判 7 项缺口，经内网进展确认后收敛为 2 项主战场 + 1 项情报任务。信创因算力已用昇腾而事实性半解决。
G1 模型端已解决

8×昇腾 910B3（6T 盘，全员可访）。DeepSeek V4 Flash + GLM 5.3 Flash，8bit 量化，07-31 正式版权重。开源国产权重随发随接，智谱 / 千问 Flash 多模态可立刻适配。昇腾即信创算力，G7 半边顺带解决。

转入例行更新：新权重 → 量化 → 上线
G2 + G3 工程桥已调通

CATIA 桥、STAR-CCM+ 桥均基于开源 MCP + 调节脚本 + 技能，本地已跑通。

从开发任务降级为打包搬运：进离线包或内网 git
G4 数据面主战场

方向修正：P-ACE 外部数据暂不接入，重点为内网 OA（CMOS 等平台）技术文件。已爬约 1 万份文档与技术报告，完整性未验收但年底交付口径已够。

Q4 头号工程：清洗 → 分类 → 建库 → 检索（civair-kb 模式复用，v1 有使用价值即可）
G5 团队协作半解决

约束：内网端口暴露需登记。底子：模型服务器全员可访 + 个人虚拟机共享文件夹兜底。待办：Linux 组权限三步配置（建组 → 加人 → setgid 目录），无需 root，管理员 30 分钟。

短期：共享目录先行；长期：等端口审批
G6 权限审计转情报

年底前不自研。跟踪 DSH 沙箱模型（research/08 已有底）+ 英伟达 / OpenAI / Anthropic 的 agent 权限设计 + 开源沙箱方案。

可产出：Agent 权限设计开源方案扫描报告（加分交付物）
G7 信创半解决

算力侧已事实满足（昇腾）。OS 适配（银河麒麟 / 统信）搁置，DSH 为 Node 跨平台，真到那天成本可控。
