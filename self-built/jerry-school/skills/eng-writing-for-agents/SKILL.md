# 为 agent 写作（Writing for Agents）

写给 agent 的任何文档（技能、`AGENTS.md`/`CLAUDE.md`、指针可达的文档）的通用参考。

## 两种负载

你加的每份文档、每个指针都花两种预算之一：

- **Context load**：常驻材料对窗口的成本——AGENTS.md 的一行、技能的 description。每轮都付输入费，每个 token 都花注意力预算，无论是否触发。
- **Cognitive load**：对人的成本——哪些文档存在、何时取哪个，人是索引。不是要最小化的成本，是人能动性的价格：花在人的判断重要处，在不重要处移除。

只有指针能到达的材料逃出 context load，代价是指针自己那一行；没有指针的材料全靠 cognitive load 驮着。

## Context pointer 三规则

指针的**措辞**（不是目标）决定 agent 何时以及多可靠地到达材料。必达目标配弱措辞指针是方差 bug：先磨措辞，磨不动才内联。

1. **触发词前置**——指针的前几个词是触发工作发生的地方。
2. **一个分支一个触发**——同义词重命名同一分支 = 一个分支写两遍，塌掉。
3. **删掉正文已带的身份信息**。

## 信息层级

文档由两种内容组成：**步骤**（有序动作）与**参考**（按需查的定义/规则/事实）。核心决策是每块内容放在梯子的哪一级：

1. **In-file step** 主层：agent 按序执行的动作。
2. **In-file reference** 平层：同一层级的规则集是合法排列，不是坏味。
3. **Disclosed reference**：推出文件、藏在指针后、按需加载。

分支检验：所有分支都需要的内联；只有部分分支到达的放指针后。下推太少顶层臃肿；下推太多埋掉真正需要的材料——这个张力就是整个决策。**Co-location**：一个概念的定义/规则/注意事项放同一标题下，读一处带出邻居。**Sprawl**（太长）即使每行都活也是失败：注意力在冗余上变薄，治法就是梯子。

## 完成判据两性质

每一步以**完成判据**收尾——告诉 agent 做完的条件：

- **清晰度**：能判 done 与不 done 吗？模糊边界（"已达成共识"）招来**提前收工**。防御顺序：先锐化边界（本地且便宜）；只在边界不可约的模糊*且*观察到赶工时，才把后续步骤藏过真实上下文边界（handoff/子代理派遣才算边界，内联调用不清空任何东西）。
- **Demand**：要求多高。"每个改动模型都核账"逼出腿活，"产出变更清单"不逼。最强判据既可查又穷尽。

## 引导词（leading word）

预训练里已有的紧凑概念（tracer bullets、fog of war、tight、red）——以 token 而非句子重复，用最少的 token 招募模型已有先验、锚住整片行为。它锚两次：正文里锚**执行**（词一出现就取同一行为），指针里锚**调用**（你的提示词/文档/代码库共享同一语言时到达更可靠）。自造词不招募先验：先找现成词。同一件事在三个站点展开表述，就是求塌缩成一个 token 的信号。

**否定是失败模式**：禁令把被禁行为拖进上下文让它更可用（"别想大象"，大象就是全部）。说正向目标（"注释写一行"），被禁行为根本不出现。禁令只在无法正向表述的硬护栏处配用，且必须配正向目标。

## 修剪纪律

- **单一事实源**：每个意义只有一个权威位置。**duplication**（同一意义多处）与引导词（同一 token 有意重复）相反——token 可重复，意义永不重复。
- **环境也是事实源**（`package.json` scripts、目录结构、`--help` 输出）：复述环境的文档是 **cache**，只在查找昂贵时才配存在。只缓存 agent 看不出来的：未成文约定、选择背后的理由、config 不认账的坑。
- 逐行查 **relevance**：还与文档的目的相关吗？默认命运是**沉积**（sediment）——加感觉安全、删感觉危险，直到要钻穿积层找活的。
- 逐句猎 **no-op**：模型默认就遵守的指令说了白说。检验是模型相对的（跑文档见分晓，不靠辩论）；失败的句子整句删，别删词。
